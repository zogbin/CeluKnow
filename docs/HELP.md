## 快速开始

### 创建文档
1. 点击首页右上角的 **新建文档** 按钮
2. 输入文档标题
3. 选择可见性（私有/公开）
4. 点击创建即可进入编辑页面

### 编辑文档
- 使用 Markdown 语法编写内容
- 支持实时预览
- 自动保存历史版本

## 知识图谱

### 什么是知识图谱
知识图谱以可视化方式展示文档之间的**引用关系**，帮助您理清知识脉络，发现相关联的内容。

### 查看知识图谱
1. 点击任意文档页面右上角的 **知识图谱** 按钮
2. 弹出窗口展示以当前文档为中心的关联图谱
3. 点击图中的节点可跳转到对应文档

### 图谱说明
- **中心节点**：当前查看的文档
- **关联节点**：与当前文档有引用关系的其他文档
- **线条**：表示文档间的引用关系
- **方向**：从引用文档指向被引用文档

### 使用建议
- 通过知识图谱可以发现文档间的隐藏关联
- 梳理知识体系时，知识图谱能帮助找到相关资料
- 撰写新文档时，可参考图谱避免重复内容

### 文档链接语法
使用 `[[文档标题]]` 语法可以在文档中引用其他文档，建立知识关联：

```markdown
这是一段关于 [[人工智能]] 的介绍。

想了解更多 [[机器学习]] 的内容，请参考相关文档。
```

当文档中出现 `[[文档标题]]` 格式的链接时：
- 系统会自动识别并建立文档间的引用关系
- 知识图谱会展示这些关联
- 点击链接可直接跳转到对应文档
- 如果目标文档不存在，链接仍会显示但点击无效果

## 多用户协作

### 用户角色
系统支持多用户使用，每个用户：
- 拥有独立的文档空间
- 可以管理自己的文档、分类、标签
- 可以对公开文档进行评论和点赞

### 公开与私有
- **私有文档**：仅创建者本人可见
- **公开文档**：所有登录用户可见

### 协作流程
1. 用户 A 创建公开文档
2. 用户 B 登录后可以查看该文档
3. 用户 B 可以点赞、评论
4. 评论会显示评论者头像和名称

### 管理自己的内容
- 在个人中心可以统一管理自己创建的所有文档
- 支持批量删除文档、评论、点赞记录

## 导入导出

### 批量导入
支持导入 **Markdown (.md)** 文件和 **ZIP 压缩包**：

#### 单文件导入
- 支持直接上传 .md 文件

#### ZIP 批量导入
- 将 Markdown 文件放入文件夹中
- 将文件夹打包为 ZIP 文件
- 导入时自动按文件夹名创建分类

```
my-docs.zip
├── 财经/
│   ├── 货币政策.md
│   └── 股市分析.md
├── 科技/
│   └── AI发展.md
└── 思考/
    └── 读书笔记.md
```

#### Front Matter 支持
导入的文档支持 YAML 头部元数据：

```markdown
---
title: 文档标题
category: 分类名称
tags: 标签1, 标签2
visibility: public
author: 用户名
created_at: 2026-05-01 10:00:00
updated_at: 2026-05-02 15:30:00
---

文档内容...
```

| 属性 | 说明 | 示例 |
|------|------|------|
| title | 文档标题 | `title: 我的文档` |
| category | 分类名称 | `category: 财经` |
| tags | 标签（逗号分隔） | `tags: 重要, 推荐` |
| visibility | 可见性 | `visibility: public` |
| author | 作者用户名 | `author: admin` |
| created_at | 创建时间 | `created_at: 2026-05-01 10:00:00` |
| updated_at | 更新时间 | `updated_at: 2026-05-02 15:30:00` |

### 导出
1. 点击首页的 **导出** 按钮
2. 系统会下载一个 ZIP 文件
3. ZIP 内按分类组织，包含所有文档

## 个人中心

### 查看我的内容
点击左上角用户名进入个人中心，可以查看：
- 我的文档
- 我的点赞
- 我的评论

### 批量操作
- 勾选项目后可以进行批量删除
- 删除文档会同时刷新左侧文档树

### 修改密码
1. 点击右上角的 **修改密码** 按钮
2. 输入新密码（至少6位）
3. 确认后即可修改

## 常见问题

### Q: 如何设置文档为公开？
A: 创建文档时选择"公开"，或在文档编辑页面修改可见性。

### Q: ZIP 导入后分类为空？
A: 确保文件夹命名正确，系统会自动按文件夹名匹配或创建分类。

### Q: 如何恢复误删的文档？
A: 系统会自动保存历史版本，可在文档编辑页面查看历史。
