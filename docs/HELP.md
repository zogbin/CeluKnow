## 快速开始

### 创建文档
1. 点击首页右上角的 **新建文档** 按钮
2. 输入文档标题
3. 选择可见性（私有/公开）
4. 点击创建即可进入编辑页面

### 编辑文档
- 使用 Markdown 语法编写内容
- 支持实时预览
- 自动保存历史版本

## 文档版本

### 什么是版本
同一标题的文档可以存在多个版本（v0、v1、v2...），每个版本独立编辑、独立保存。

### 创建新版本
1. 打开文档后点击工具栏的 **版本** 图标（版本数大于 1 时显示）
2. 在版本面板点击 **另存为新版本**
3. 系统自动复制当前内容并创建新版本

### 版本管理
- **查看版本**：点击 **版本** 图标打开版本面板，列出该标题所有版本
- **切换版本**：在版本列表中点击某个版本，直接跳转到该版本页面
- **删除版本**：非当前版本的条目右侧有 **删除** 按钮
- **编辑版本**：每个版本独立编辑，保存只影响当前版本

### 版本号显示
- 文档标题旁显示 `v0`、`v1` 等标签
- 首页列表、侧边栏也显示版本号
- 侧边栏和图谱只显示每标题的最新版本

### Wiki 链接引用版本
- `[[文档标题]]` → 指向最新版本
- `[[文档标题(v2)]]` → 指向指定版本

## 知识图谱

### 什么是知识图谱
知识图谱以可视化方式展示文档之间的**引用关系**，帮助您理清知识脉络，发现相关联的内容。

### 查看知识图谱
1. 点击任意文档页面右上角的 **知识图谱** 按钮
2. 弹出窗口展示以当前文档为中心的关联图谱
3. 点击图中的节点可跳转到对应文档

### 图谱说明
- **中心节点**：当前查看的文档
- **关联节点**：与当前文档有引用关系的其他文档
- **线条**：表示文档间的引用关系
- **方向**：从引用文档指向被引用文档

### 使用建议
- 通过知识图谱可以发现文档间的隐藏关联
- 梳理知识体系时，知识图谱能帮助找到相关资料
- 撰写新文档时，可参考图谱避免重复内容

### 文档链接语法
使用 `[[文档标题]]` 语法可以在文档中引用其他文档，建立知识关联：

```markdown
这是一段关于 [[人工智能]] 的介绍。

想了解更多 [[机器学习]] 的内容，请参考相关文档。
```

当文档中出现 `[[文档标题]]` 格式的链接时：
- 系统会自动识别并建立文档间的引用关系
- 知识图谱会展示这些关联
- 点击链接可直接跳转到对应文档
- 如果目标文档不存在，链接仍会显示但点击无效果

## 多用户协作

### 用户角色
系统支持多用户使用，每个用户：
- 拥有独立的文档空间
- 可以管理自己的文档、分类、标签
- 可以对公开文档进行评论和点赞

### 公开与私有
- **私有文档**：仅创建者本人可见
- **公开文档**：所有登录用户可见

### 协作流程
1. 用户 A 创建公开文档
2. 用户 B 登录后可以查看该文档
3. 用户 B 可以点赞、评论
4. 评论会显示评论者头像和名称

### 管理自己的内容
- 在个人中心可以统一管理自己创建的所有文档
- 支持批量删除文档、评论、点赞记录

## 导入导出

### 批量导入
支持导入 **Markdown (.md)** 文件和 **ZIP 压缩包**：

#### 单文件导入
- 支持直接上传 .md 文件

#### ZIP 批量导入
- 将 Markdown 文件放入文件夹中
- 将文件夹打包为 ZIP 文件
- 导入时自动按文件夹名创建分类

```
my-docs.zip
├── 财经/
│   ├── 货币政策.md
│   └── 股市分析.md
├── 科技/
│   └── AI发展.md
└── 思考/
    └── 读书笔记.md
```

#### Front Matter 支持
导入的文档支持 YAML 头部元数据：

```markdown
---
title: 文档标题
category: 分类名称
tags: 标签1, 标签2
visibility: public
author: 用户名
created_at: 2026-05-01 10:00:00
updated_at: 2026-05-02 15:30:00
---

文档内容...
```

| 属性 | 说明 | 示例 |
|------|------|------|
| title | 文档标题 | `title: 我的文档` |
| category | 分类名称 | `category: 财经` |
| tags | 标签（逗号分隔） | `tags: 重要, 推荐` |
| visibility | 可见性 | `visibility: public` |
| author | 作者用户名 | `author: admin` |
| created_at | 创建时间 | `created_at: 2026-05-01 10:00:00` |
| updated_at | 更新时间 | `updated_at: 2026-05-02 15:30:00` |

### 导出
1. 点击首页的 **导出** 按钮
2. 系统会下载一个 ZIP 文件
3. ZIP 内按分类组织，包含所有文档

## 会议管理

### 主要功能
- 会议资料共享：支持多人共享PDF、PPT、Word、Excel等多种格式文件
- 多议程支持：会议可添加多个议程，每个议程独立管理
- 文件夹上传：支持按文件夹分类整理会议资料
- 时间提醒：清晰显示会议时间、进行中/已完成状态
- WPS集成：支持直接在WPS中打开编辑会议资料

### 操作说明
1. 创建会议时填写标题、时间、地点信息
2. 添加多个议程项，每个议程可单独上传相关资料
3. 拖拽文件到会议区域即可快速上传
4. 已完成的会议资料自动锁定，仅可查看

## CLI 命令行工具

CeluKnow 提供 CLI 工具供AI模型、自动化脚本和定时任务使用。

### 安装

```bash
cd cli
npm install
npm run link
```

### 快速开始

```bash
# 1. 设置环境变量（添加到 ~/.bashrc 或 ~/.zshrc 持久化）
export CELUKNOW_SERVER=http://localhost:3001

# 2. 登录获取 token（有效期 7 天）
celuknow login -u your_username -p your_password

# 3. 设置 token 环境变量
export CELUKNOW_TOKEN=your_token

# 4. 开始使用
celuknow list                    # 查看文档列表
celuknow search "关键词"          # 搜索文档
celuknow get 1                   # 查看文档详情
celuknow import file.md          # 导入单个文件
celuknow import ./docs           # 导入整个目录
celuknow export -o ./backup      # 导出为 ZIP
celuknow delete 1 --force        # 删除文档
```

> **注意**：Token 有效期为 7 天，过期后需要重新登录获取新 token。

### 命令说明

| 命令 | 说明 | 示例 |
|------|------|------|
| `login` | 用户登录获取 token | `celuknow login -u admin -p 123456` |
| `query <text>` | **深度查询**（FTS5 BM25 排序，推荐） | `celuknow query "教程" --full --json` |
| `index` | 知识索引概览 | `celuknow index --json` |
| `get <id>` | 获取文档详情 | `celuknow get 123 --related` |
| `search <text>` | 搜索文档（旧版 LIKE 搜索） | `celuknow search "教程" --limit 10` |
| `list` | 列出文档 | `celuknow list --limit 20` |
| `import` | 导入 Markdown | `celuknow import ./docs --category 技术` |
| `export` | 导出为 ZIP | `celuknow export -o ./backup` |
| `delete` | 删除文档 | `celuknow delete 123 --force` |

### `query` 命令详解

`celuknow query` 使用 SQLite FTS5 BM25 全文索引进行毫秒级搜索，支持中文分词和相关性排序。

**选项：**

| 选项 | 说明 | 默认 |
|------|------|------|
| `-l, --limit <n>` | 最大结果数 | 10 |
| `--full` | 返回完整文档内容 | false |
| `--related` | 返回关联文档（同分类） | false |
| `--explain` | 显示 FTS5 BM25 评分明细 | false |
| `--min-score <n>` | 最低分数阈值 | 0 |
| `--json` | JSON 格式输出 | false |
| `--md` | Markdown 格式输出 | false |

**使用示例：**

```bash
# AI 消费用：搜索 + 完整内容 + JSON
celuknow query "机器学习" -l 5 --full --json

# 探索用：搜索 + 关联内容
celuknow query "项目规划" --related

# 精确用：高阈值过滤
celuknow query "错误处理" --min-score 1.0

# 诊断用：看为什么匹配
celuknow query "API设计" --explain

# 展示用：Markdown 输出
celuknow query "架构设计" -l 3 --md
```

**输出示例（JSON）：**

```json
{
  "query": "机器学习",
  "total": 3,
  "results": [
    {
      "id": 7,
      "title": "机器学习入门",
      "score": 1.52,
      "snippet": "内容摘要...",
      "content": "完整内容（有 --full 时）",
      "tags": "AI,教程",
      "category_names": "技术",
      "explain": {
        "method": "FTS5 BM25",
        "query": "机器学习"
      }
    }
  ]
}
```

### 全局选项

所有命令支持以下全局选项：
- `-s, --server <url>` - 服务端地址
- `-t, --token <token>` - 认证 token

也可以通过环境变量设置：
- `CELUKNOW_SERVER` - 服务端地址
- `CELUKNOW_TOKEN` - 认证 token

### 优先级

1. 命令行选项（最高）
2. 环境变量
3. 默认值（最低）
